# OpenCode Setup для Windows

[English](readme.md)

Установщик OpenCode CLI для Windows, который настраивает пользовательскую конфигурацию RouterAI, глобальные инструкции агента и управляемую системную политику безопасности.

## Установка

Требования: Windows x64, Windows PowerShell 5.1 или PowerShell 7+, подключение к интернету. Права администратора нужны только для создания или обновления защищённых системных файлов политики.

Перед запуском проверьте содержимое установщика. Для локальной копии репозитория:

```powershell
git clone https://github.com/ErrOzz/opencode_setup.git
Set-Location opencode_setup
.\install.ps1
```

Также можно запустить установщик напрямую из репозитория:

```powershell
irm https://raw.githubusercontent.com/ErrOzz/opencode_setup/refs/heads/main/install.ps1 | iex
```

При запуске из локальной копии установщик использует файлы рядом с `install.ps1`. При удалённом запуске он загружает их из `-BaseUrl` (по умолчанию — ветка `main`). Для воспроизводимой установки укажите проверенный тег или commit в `-BaseUrl`.

## Что устанавливается

| Компонент | Расположение | Поведение |
| --- | --- | --- |
| OpenCode CLI | `%LOCALAPPDATA%\Programs\opencode\bin` | Устанавливает или обновляет последнюю версию CLI для Windows x64 и добавляет папку в пользовательский `PATH`. |
| Пользовательская конфигурация | `%USERPROFILE%\.config\opencode\opencode.jsonc` | Создаётся из `opencode-user.jsonc`, если файла ещё нет. |
| Глобальные инструкции | `%USERPROFILE%\.config\opencode\AGENTS.md` | Создаются из `AGENTS.md` репозитория, если файла ещё нет. |
| Управляемая системная политика | `%ProgramData%\opencode\opencode.json` | Устанавливается из `opencode-system.jsonc`; обновляется, только если файл отсутствует или отличается. |
| Локальные дополнения политики | `%ProgramData%\opencode\opencode.jsonc` | Создаются как шаблон, если файла ещё нет, и сохраняются при последующих запусках. Для машинных исключений редактируйте файл с правами администратора. |

Установщик запрашивает `ROUTERAI_API_KEY`, только если переменная ещё не задана. Ключ считывается из окружения и не сохраняется в пользовательской конфигурации.

## Обновление

Повторный запуск установщика обновляет CLI и управляемую системную политику. Существующие пользовательская конфигурация и `AGENTS.md` по умолчанию сохраняются.

Чтобы заменить эти два файла версиями из репозитория, предварительно сохраните собственные изменения и запустите:

```powershell
.\install.ps1 -UpdateConfig
```

Чтобы обновить их напрямую из репозитория без клонирования, скопируйте и запустите:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/ErrOzz/opencode_setup/refs/heads/main/install.ps1))) -UpdateConfig
```

Перед заменой каждого существующего файла создаётся резервная копия с временной меткой и расширением `.bak`. Локальные дополнения в `%ProgramData%\opencode\opencode.jsonc` никогда не перезаписываются.

Параметры:

- `-UpdateConfig` — заменить существующие пользовательскую конфигурацию и глобальные инструкции, сохранив резервные копии.
- `-SkipSystemPolicy` — не изменять `%ProgramData%\opencode`; установка CLI и пользовательских файлов продолжится.
- `-BaseUrl <url>` — использовать другой URL репозитория как источник файлов конфигурации.

## Модель безопасности

Системная политика защищена от изменений обычными пользовательскими процессами и имеет приоритет над конфигурацией проекта. Машинные исключения следует добавлять в отдельный локальный файл дополнений, который загружается после управляемой политики.

Эта политика не является песочницей: OpenCode работает с правами вашей учётной записи Windows. Проверяйте изменения политики и внимательно подтверждайте выполнение команд.

Эффективную конфигурацию OpenCode можно посмотреть командой:

```powershell
opencode debug config
```
